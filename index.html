Variabel, Tipe Data, Input/Output, & Flowchart

Fondasi utama pemrograman C# (.NET). Memahami alur kompilasi, tipe data presisi, aturan penamaan, serta pembuatan flowchart standar.

Pola Utama & Eksekusi Program

Semua program komputer mengikuti struktur dasar: INPUT → PROSES → OUTPUT.

Alur Kompilasi C#:
Program.cs → Kompiler (Roslyn) → Bytecode (IL) → CLR (JIT Engine) → Executable
Perintah Terminal .NET CLI:
  • dotnet new console -n NamaApp (Buat project)
  • dotnet build (Cek syntax & kompilasi)
  • dotnet run (Jalankan program)

Variabel & Scope

  • Siklus: Deklarasi int stok; → Inisialisasi stok = 10; → Assignment stok += 5;
  • Aturan Nama: Tidak boleh diawali angka, tanpa spasi/tanda min (-), bukan keyword, dan Case-Sensitive (nama ≠ Nama).
  • Konvensi Penulisan: Variabel lokal pakaii camelCase, Method/Class pakai PascalCase, Private Field pakai _camelCase.
  • Kata Kunci Penting: var (Tipe implisit tetapi tetap *strongly-typed*), const (Wajib diisi saat compile time), readonly (Bisa diisi saat runtime).

Jenis Data Praktis Tipe Data C# Catatan Penting / Suffix
Umur, Jumlah barang, Stok int Bilangan bulat (-2.1 miliar s.d +2.1 miliar).
NIK, Nomor Rekening Bank long / string Gunakan string jika tidak ada operasi aritmatika.

Jebakan Ujian: Ekspresi 0.1 + 0.2 == 0.3 bernilai False pada tipe double akibat precision rounding IEEE 754, namun bernilai True pada tipe decimal. Selain itu, int.MaxValue + 1 menghasilkan overflow menjadi -2147483648 tanpa error jika tidak di dalam blok checked.

Safe Parsing Code Pattern

Console.ReadLine() selalu menghasilkan String. Jangan gunakan int.Parse tanpa penanganan error karena program akan crash jika pengguna memasukkan huruf. 

Console.Write("Masukkan angka umur: ");
string input = Console.ReadLine();

// Gunakan TryParse untuk konversi aman (anti-crash)
bool isBerhasil = int.TryParse(input, out int umur);

if (!isBerhasil || umur <= 0)
{
    Console.WriteLine("Error: Input bukan angka positif yang valid!");
}
else
{
    Console.WriteLine($"Umur Anda: {umur} tahun.");
}

String Interpolation & Format Specifier

Gunakan awalan $ untuk memasukkan variabel secara langsung ke dalam string: $"Nama: {nama}".

"{val:F2}" Fixed Point (2 Angka Desimal) → 3.14
"{val:N0}" Number dengan pemisah ribuan → 1,000,000
"{val:C0}" Currency / Mata Uang → Rp50.000
"{val:P1}" Percentage → 85.5%
"{val, -10}" Rata Kiri Kolom (Lebar 10 Karakter)

Minggu 04

Percabangan: IF-ELSE, Switch-Case & Operator Relasional

Memahami pengambilan keputusan dalam kode. Penggunaan operator pembanding, tabel kebenaran, serta sintaks percabangan modern.

Operator Pembanding (Relasional) Complete Guide

Anggap setiap operator sebagai pertanyaan Ya/Tidak yang menghasilkan nilai true atau false.

== Sama Dengan

Memeriksa kecocokan nilai persis.

pin == 123456

!= Tidak Sama Dengan

Memeriksa apakah nilainya berbeda.

bayar != totalHarga

> Lebih Dari

Nilai batas TIDAK ikut dihitung.

belanja > 100000

< Kurang Dari

Batas atas TIDAK ikut dihitung.

umur < 12

>= Minimal / Lebih Sama

Nilai batas IKUT dihitung.

tinggi >= 120

<= Maksimal / Kurang Sama

Nilai batas IKUT dihitung.

berat <= 20

Trik Cepat Mengingat Operator:
  • Satu '=' adalah Pengisian (Assignment), Dua '==' adalah Pertanyaan (Comparison). x = 5 (isi nilai 5), x == 5 (apakah x sama dengan 5?).
  • Tanda Sama Selalu di Belakang: Tulis >= dan <=, BUKAN => atau =< (akan sintaks error).
  • Rentang nilai ganda di C#: Wajib gunakan operator logika &&. Contoh: umur >= 20 && umur <= 40 (Bentuk 20 <= umur <= 40 TIDAK valid di C#).

Konversi Nilai Angka ke Huruf (IF-ELSE) 

if (nilai > 85) 
    huruf = "A";
else if (nilai > 75) 
    huruf = "AB";
else if (nilai > 65) 
    huruf = "B";
else if (nilai > 60) 
    huruf = "BC";
else if (nilai > 50) 
    huruf = "C";
else if (nilai > 40) 
    huruf = "D";
else 
    huruf = "E";

*Catatan batas: Nilai 85 tepat menghasilkan "AB", bukan "A" karena menggunakan > bukan >=.

Struktur Switch-Case & Ternary 

// Ternary Operator (Kondisi Singkat)
string status = (nilai >= 75) ? "Lulus" : "Remidi";

// Switch Case Standar
switch (kodeHari)
{
    case 1: Console.WriteLine("Senin"); break;
    case 2: Console.WriteLine("Selasa"); break;
    default: Console.WriteLine("Hari Libur/Invalid"); break;
}

*Di C#, kata kunci break wajib di setiap blok case untuk mencegah fall-through (menghindari CS0163).

Minggu 06

Percabangan Bersarang (Nested IF)

Logika bertingkat di mana suatu percabangan berada di dalam percabangan lainnya. Analogi: Masuk ATM → Cek PIN → Cek Penarikan Saldo.

Aturan Emas Nested IF

Kondisi di tingkat dalam (inner IF) HANYA AKAN DIPERIKSA jika kondisi di tingkat luar (outer IF) bernilai true. Jika kondisi luar false, blok dalam diabaikan secara total. 

if (nilai >= 75)
{
    Console.WriteLine("Status: LULUS");
    
    // Nested IF di dalam blok LULUS
    if (nilai >= 90)
    {
        Console.WriteLine("Predikat: A (Sangat Memuaskan)");
    }
    else
    {
        Console.WriteLine("Predikat: B (Memuaskan)");
    }
}
else
{
    Console.WriteLine("Status: TIDAK LULUS");
}
Input Nilai Cek (≥ 75) Cek (≥ 90) Output Terminal
95 True True LULUS, Predikat A
80 True False LULUS, Predikat B
60 False Tidak Dicek TIDAK LULUS

1. Pitfall Danling Else

Tanpa kurung kurawal { }, pernyataan else akan selalu menempel pada if terdekat di atasnya, yang dapat memicu logika bug fatal.

2. Nested vs Operator &&

Gunakan && jika semua syarat sepadan dan menghasilkan output sama. Gunakan Nested IF jika setiap tingkatan membutuhkan pesan error/aksi berbeda.

3. Kedalaman Indentasi

Hindari membuat Nested IF lebih dari 3 tingkat (*Arrow Anti-Pattern*). Pecah logika menggunakan klausa penjaga (*guard clauses*) atau return awal.
